# sheeba-site — media

Media archive for the website of artist **Sheeba Manghat Narayanan** (Instagram [@soulfulwallarts](https://www.instagram.com/soulfulwallarts)).

All media lives under [`media/`](media/). See [`media/00 - README & INDEX.md`](<media/00 - README & INDEX.md>) for the full inventory and notes.

## Structure

```
media/
├── 00 - README & INDEX.md                              full inventory + caveats
├── 1 - Glimpses of Kerala (2010) - Originals (Hi-Res)/ clean high-res DSLR photos, one folder per painting
├── 2 - Instagram Reels (captioned videos + frames)/    promo reels + extracted frames + contact sheets
└── 3 - Extra Media (process videos & misc)/            process/making-of clips and extra photos
```

## Series in this archive

*Glimpses of Kerala* (2010) — paintings include Malabaris, Kochi Catch, Sunset, Survival, Nostalgia, Serenity, Elegant Stride, Thekkady Treasure, and the Village Competition set.

## Notes

- The **clean, text-free artwork** is in folder 1 (DSLR originals). The Instagram reels in folder 2 have the artist's caption text baked into the video.
- The TV-broadcast episode (*ARTSCAPE EPI-61*) in `1 - .../_Press, Media & Archive/` was transcoded from the original 524 MB MPEG-2 to a web-friendly H.264 MP4 to fit within GitHub's file-size limits.
